Mettre à jour

  1. Dans Dors, exportez vos données (Réglages, « Exporter mes données »), par précaution.
  2. Téléchargez la nouvelle version sur la page de Dors, puis ouvrez le fichier.
  3. Android l'installe par-dessus l'ancienne : vos nuits, votre journal et votre code Dors complet sont gardés.

Android ne remplace Dors que par une version signée avec le même certificat. Un message « application non installée » ou « en conflit » signale un fichier qui ne vient pas d'EXODE : ne désinstallez pas Dors pour le forcer, vous perdriez vos données. Écrivez-nous plutôt.
