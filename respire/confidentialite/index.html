Respire

Politique de confidentialité

Dernière mise à jour : 12 novembre 2026

Nous ne collectons rien. Absolument rien.
Respire fonctionne entièrement hors ligne. L'application n'a pas de compte, pas de serveur, pas de service de synchronisation des données personnelles. Tout ce que vous écrivez reste sur votre téléphone.

Qui est responsable de cette application ?

Respire est éditée à titre non professionnel par EXODE (Exode Multimédia). Pour toute question relative à cette politique, vous pouvez écrire à contact@exode-media.com.

Quelles données sont collectées ?

Aucune. Nous n'avons accès à rien de ce que vous saisissez. Il n'existe ni compte utilisateur, ni identifiant, ni statistique d'usage, ni outil de mesure d'audience, ni publicité, ni service tiers d'analyse. Les informations saisies ne sont pas envoyées à un service d'analyse ou de synchronisation.

Quelles données restent sur votre téléphone ?

Ces informations sont enregistrées dans une base de données locale, dans l'espace privé de l'application, accessible à elle seule :

DonnéePourquoi

La sauvegarde automatique vers le compte Google est désactivée (allowBackup="false") : vos données ne partent pas non plus dans le cloud de sauvegarde Android, ni lors d'un transfert vers un nouvel appareil.

Gratuité

Respire est entièrement gratuite : aucun abonnement, aucun achat intégré et aucune publicité. Aucun paiement ni aucune carte bancaire ne sont nécessaires pour utiliser ses fonctionnalités.

Dictée vocale facultative

Le microphone est demandé uniquement si vous lancez une dictée. Respire utilise exclusivement la reconnaissance vocale embarquée sur l'appareil : l'audio n'est ni enregistré par Respire ni envoyé à un serveur, et aucun service vocal en ligne n'est utilisé en secours. Si la reconnaissance embarquée n'est pas disponible, la dictée reste désactivée et la saisie au clavier reste possible. Seul le texte obtenu est conservé, dans votre cahier de bord.

Guidage vocal

Les exercices de respiration peuvent être lus à voix haute par le moteur de synthèse vocale installé sur votre téléphone. Respire lui transmet uniquement les consignes de l'exercice, jamais le contenu de votre journal.

Et les notifications ?

Les rappels sont locaux : ils sont programmés par votre téléphone, pour votre téléphone. Aucune notification ne transite par un serveur. La permission de notifier vous est demandée à la fin de la configuration initiale, jamais au premier écran ; vous pouvez la refuser, et désactiver chaque rappel individuellement dans les Réglages.

Permissions Android

Respire ne demande pas la permission d'accès à Internet : l'application ne peut techniquement rien envoyer. Les seules permissions déclarées sont :

  • Notifications (et vibration, maintien bref du processeur) : afficher les rappels locaux ;
  • Démarrage de l'appareil : reprogrammer les rappels après un redémarrage du téléphone ;
  • Microphone : uniquement pendant une dictée que vous lancez vous-même.

Vos droits, en pratique

Puisque rien ne quitte votre appareil, vous gardez la maîtrise complète de vos données à tout instant, depuis les Réglages de l'application :

  • Exporter : récupérez l'intégralité de vos données en JSON et en CSV, ou des fiches PDF (par addiction, sommeil, bilan du mois), pour les archiver ou les montrer à un professionnel de santé si vous le souhaitez.
  • Supprimer : un bouton, une confirmation, et tout est effacé définitivement.
  • Désinstaller : la suppression de l'application efface également toutes les données.

Vos données sont conservées sur l'appareil tant que vous ne les supprimez pas. Comme elles ne nous sont jamais transmises, nous ne pouvons ni les consulter, ni les corriger, ni les restaurer à votre place : pensez à l'export si vous changez de téléphone.

Partage volontaire

L'export utilise le partage standard d'Android (ou d'iOS dans la version web) : c'est vous qui choisissez la destination (mail, fichiers, messagerie…). Ce que vous en faites ensuite relève des conditions de l'application que vous aurez choisie. Ce partage nécessite votre action explicite.

Appels vers les services d'aide

L'écran Ressources propose d'appeler des numéros publics (Tabac Info Service, Drogues Info Service, Alcool Info Service, 3114, et les urgences 15 et 112). Toucher « Appeler » ouvre simplement votre application Téléphone avec le numéro pré-rempli. Nous ne sommes informés d'aucun appel, et ces services disposent de leurs propres règles de confidentialité.

Enfants

Cette application s'adresse aux personnes majeures engagées dans une démarche de sevrage. Elle ne vise pas les enfants et ne collecte de toute façon aucune donnée les concernant.

Ce que cette application n'est pas

Respire n'est pas un dispositif médical. Elle ne pose aucun diagnostic et ne remplace ni médecin ni pharmacien. Le sevrage de l'alcool, en particulier, peut être physiquement dangereux : ne vous arrêtez jamais brutalement seul si vous buvez beaucoup, parlez-en à un professionnel de santé.

Version web pour iPhone

Sur iPhone, Respire s'utilise depuis le navigateur, à l'adresse exode150-creator.github.io/respire-iphone, ajoutée à l'écran d'accueil. C'est la même application, avec les mêmes règles :

  • Vos données restent dans le téléphone, dans le stockage que le navigateur réserve à Respire (base de données locale). Elles ne sont envoyées à personne : ni à nous, ni à l'hébergeur.
  • Hébergement : le programme, les images et les polices de l'application sont téléchargés depuis GitHub Pages, le service d'hébergement de GitHub, puis gardés en cache pour fonctionner hors ligne. Comme pour ce site, ces téléchargements impliquent des échanges techniques avec l'hébergeur, notamment l'adresse IP, que GitHub conserve pour la sécurité de son service. Ils ne contiennent rien de ce que vous saisissez. Aucun script ni aucune police n'est chargé ailleurs.
  • Pas de rappels, pas de dictée, pas de guidage vocal dans cette version : aucune notification ni aucun microphone n'est demandé.
  • Effacement : supprimer Respire de l'écran d'accueil, ou effacer les données de site de Safari, supprime aussi vos données Respire. Pensez à l'export.

Ce site web

Ce site, exode-media.com, est hébergé par GitHub Pages (GitHub, Inc.). Une consultation web implique des échanges techniques avec l'hébergeur, notamment l'adresse IP et les informations nécessaires à la livraison des pages. Le site ne dépose aucun cookie et n'utilise aucun outil de mesure d'audience ni traceur publicitaire. Le fichier d'installation Android (Respire.apk) est téléchargé depuis GitHub. Le fonctionnement hors ligne décrit ci-dessus concerne l'application.

Liens externes

Si vous ouvrez une ressource externe, votre navigateur applique les conditions du site consulté. Ces consultations ne transmettent pas votre journal Respire.

Modifications

Si cette politique évolue, la date de mise à jour en haut de page changera. Comme l'application ne collecte rien, une modification ne peut aller que dans un sens : celui de la transparence.
