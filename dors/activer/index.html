Cette page reçoit le code de déblocage envoyé par e-mail après l'achat de Dors complet.

Aucun code n'a été trouvé dans ce lien. Ouvrez le lien directement depuis l'e-mail, ou recopiez le code (il commence par « DORS- ») : dans Dors, page « Dors complet », touchez « J'ai un code » et collez-le.

Votre code reste chez vous. Il est placé après le signe « # » du lien, une partie de l'adresse que le navigateur n'envoie jamais au site. Cette page le lit dans votre navigateur, sans le transmettre, et Dors le vérifie sur le téléphone, sans Internet. Voir la politique de confidentialité.
